# Ecommerce spelling (Oct 2026)

Source: "Research: spelling of 'ecommerce'" (https://docs.google.com/document/d/1LDMnSu-BwdX--nlsFhm1_dEFBWYD-E8HrTPXKhHi7sQ). This replaces the old "eCommerce" rule everywhere in English Wix copy.

**Applies to:** body copy, headings, FAQ, TL;DR, tables, CTA copy, button text, anchor text, image alt text, SEO title, meta description and excerpt.

## Use

| Write | When |
|---|---|
| **ecommerce** | The generic word, mid-sentence |
| **Ecommerce** | First word of a sentence, heading, list item or table cell, or part of a proper noun |
| **Wix Ecommerce** | The product |
| **ecomm** / **Ecomm** | Short form, with the same capitalization logic as above |

## Never

| ❌ Never write | ✅ Write instead |
|---|---|
| eCommerce, ECommerce | ecommerce (or Ecommerce at the start of a sentence) |
| Wix eCommerce | Wix Ecommerce |
| e-commerce, E-commerce | ecommerce / Ecommerce |
| Ecommerce mid-sentence, when not part of a proper noun | ecommerce |
| eComm, EComm | ecomm / Ecomm |

## Not hits (leave unchanged)

- URLs, paths and hostnames, e.g. `/ecommerce/online-store`.
- Monday board, group, topic and bucket labels used for lookups, e.g. "🛒 eCommerce", "Business & eCommerce", Quotes Library topic "eCommerce".
- Document titles, e.g. "eCommerce PMM Messaging Doc (Full)".
- Third-party proper nouns spelled their own way, e.g. "Practical Ecommerce", "WooCommerce".

## Scan (case-sensitive)

1. Flag every match of: `eCommerce`, `ECommerce`, `e-commerce`, `E-commerce`, `eComm`, `EComm` (whole words).
2. Flag every `Ecommerce` / `Ecomm` that is **not** at the start of a sentence, heading, list item or table cell and **not** part of a proper noun ("Wix Ecommerce").
3. Drop anything in the "Not hits" list above.
4. Fix each hit by replacing the word only. Don't rewrite the rest of the sentence, and don't change link URLs (anchor text spelling can change).
